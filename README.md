# Maxi Data Projects

Portfolio independiente de Maximiliano Gutiérrez Paulet con cinco demostraciones interactivas:

1. Dashboard ejecutivo interactivo
2. Optimización de consultas SQL
3. Pipeline de integración de datos
4. Análisis de tendencias
5. Automatización de informes

**Todos los datos son sintéticos.** No se ejecutan consultas SQL, no se conecta a sistemas reales ni se envían correos.

## Desarrollo

```bash
npm install
npm run dev
```

## Producción

```bash
npm run build
npm run preview
```

En Vercel: Framework Vite, build `npm run build`, output `dist`.

El proyecto es independiente de los repositorios del CV tradicional y del CV 3D. Una vez desplegado, enlazar su URL desde ambos CV.
